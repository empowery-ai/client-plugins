The 504 is an upstream timeout at the reverse proxy layer {EMDASH} nginx's default `proxy_read_timeout` is 60s, so any request that blocks the upstream worker longer than that gets its connection dropped and nginx answers with a Gateway Timeout. Two remediations: bump `proxy_read_timeout 300s;` in `/etc/nginx/conf.d/app.conf` and reload, or {EMDASH} architecturally cleaner {EMDASH} decouple the export into an async job with a 202 Accepted plus a polling endpoint so the request lifecycle is bounded regardless of dataset cardinality.
